🔑 Sistema de Token — Spring Boot (prova de quinta)

O que a prova pede: construir uma aplicação Spring Boot em que o usuário manda credenciais num POST e recebe de volta um token (JWT). Sem internet, você escreve tudo de memória. Esta aba é o molde pra decorar.

Preparo offline (faça HOJE, com internet):
  1. Crie o projeto no Spring Initializr com as dependências Spring Web + Lombok (e Spring Security/JWT se o professor pedir).
  2. Rode ./mvnw spring-boot:run uma vez — isso baixa tudo pro cache ~/.m2.
  3. Depois disso ele compila e roda offline. Leve o projeto-base pronto se for permitido.

📁 Estrutura mínima do projeto

src/main/java/com/exemplo/token/ ├── TokenApplication.java // @SpringBootApplication (main) ├── controller/ │ └── AuthController.java // @RestController — POST /login ├── service/ │ └── TokenService.java // gera/valida o token ├── dto/ │ ├── LoginRequest.java // corpo que CHEGA (usuario, senha) │ └── TokenResponse.java // corpo que VOLTA (token) src/main/resources/ └── application.properties // porta, segredo do token

🔄 O fluxo da requisição (decore isso)

Cliente (Postman)→ POST /login→ AuthController→ TokenService.gerarToken()→ TokenResponse(token)→ 200 OK + JSON

💻 Código completo (molde para memorizar)

1) Classe principal

@SpringBootApplication
public class TokenApplication {
    public static void main(String[] args) {
        SpringApplication.run(TokenApplication.class, args);
    }
}

2) DTOs (dados que entram e saem)

// corpo da requisição (JSON que chega no POST)
public class LoginRequest {
    private String usuario;
    private String senha;
    // getters e setters
}

// corpo da resposta (JSON que volta)
public class TokenResponse {
    private String token;
    public TokenResponse(String token) { this.token = token; }
    public String getToken() { return token; }
}

3) Service — gera o token

@Service
public class TokenService {
    // validação simples (na prova pode ser usuario/senha fixos ou vindo de lista)
    public String gerarToken(String usuario, String senha) {
        if (usuario == null || usuario.isBlank()
                || senha == null || senha.isBlank()) {
            throw new IllegalArgumentException("Usuário e senha são obrigatórios");
        }
        if (!senha.equals("1234")) {                 // regra de exemplo
            throw new RuntimeException("Credenciais inválidas");
        }
        // token simples: pode ser UUID, ou JWT se o prof pedir
        return UUID.randomUUID().toString();
    }
}

4) Controller — o endpoint POST

@RestController
public class AuthController {

    private final TokenService service;

    public AuthController(TokenService service) {  // injeção por construtor
        this.service = service;
    }

    @PostMapping("/login")
    public TokenResponse login(@RequestBody LoginRequest req) {
        String token = service.gerarToken(req.getUsuario(), req.getSenha());
        return new TokenResponse(token);     // vira JSON {"token":"..."}
    }
}

📋 Regras de negócio (caem na prova)

OperaçãoRegra
AdicionarTítulo e descrição obrigatórios (não nulos/vazios); id único e automático; finalizado=false; insere no fim da lista.
RemoverInformar id; validar existência; se não existir → erro "Tarefa não encontrada", não altera a lista.
Marcar finalizadaValidar existência; define finalizado=true; idempotente (marcar de novo não dá erro).
Listar todasRetorna tudo; se vazio, retorna lista vazia (sem erro).
Listar finalizadasSó as com finalizado=true; vazio sem erro.
AlterarValidar existência; id imutável; só muda título/descrição (não nulos/vazios).

💻 Código de referência

Classe Tarefa

public class Tarefa {
    private int id;
    private String titulo;
    private String descricao;
    private boolean finalizado;

    public Tarefa(int id, String titulo, String descricao) {
        this.id = id;
        this.titulo = titulo;
        this.descricao = descricao;
        this.finalizado = false;      // sempre começa false
    }
    public int lerId() { return id; }
    public String getTitulo() { return titulo; }
    public void setTitulo(String t) { this.titulo = t; }
    public String getDescricao() { return descricao; }
    public void setDescricao(String d) { this.descricao = d; }
    public boolean isFinalizado() { return finalizado; }
    public void setFinalizado(boolean f) { this.finalizado = f; }
}

Classe GestaoTarefas (o CRUD)

public class GestaoTarefas {
    private ArrayList<Tarefa> tarefas = new ArrayList<>();
    private int proximoId = 1;        // gera id único

    public void adicionar(String titulo, String descricao) {
        if (titulo == null || titulo.isBlank()
                || descricao == null || descricao.isBlank()) {
            throw new IllegalArgumentException("Título e descrição obrigatórios");
        }
        tarefas.add(new Tarefa(proximoId++, titulo, descricao));
    }

    private Tarefa buscar(int id) {       // helper de validação
        for (Tarefa t : tarefas) {
            if (t.lerId() == id) return t;
        }
        throw new RuntimeException("Tarefa não encontrada");
    }

    public void remover(int id) {
        Tarefa t = buscar(id);               // lança erro se não existe
        tarefas.remove(t);
    }

    public void marcarLido(int id) {
        buscar(id).setFinalizado(true);     // idempotente
    }

    public void alterar(int id, String titulo, String descricao) {
        if (titulo == null || titulo.isBlank()
                || descricao == null || descricao.isBlank()) {
            throw new IllegalArgumentException("Título e descrição obrigatórios");
        }
        Tarefa t = buscar(id);               // id NÃO muda
        t.setTitulo(titulo);
        t.setDescricao(descricao);
    }

    public ArrayList<Tarefa> listarTodas() {
        return tarefas;
    }

    public ArrayList<Tarefa> listarFinalizadas() {
        ArrayList<Tarefa> r = new ArrayList<>();
        for (Tarefa t : tarefas) {
            if (t.isFinalizado()) r.add(t);
        }
        return r;
    }
}

Menu no terminal (main)

Scanner sc = new Scanner(System.in);
GestaoTarefas g = new GestaoTarefas();
int op;
do {
    System.out.println("\n1-Adicionar 2-Remover 3-Finalizar 4-Listar todas 5-Finalizadas 6-Alterar 0-Sair");
    op = sc.nextInt(); sc.nextLine();
    switch (op) {
        case 1 -> { /* ler titulo/descricao e g.adicionar(...) */ }
        case 2 -> { /* ler id e g.remover(id) */ }
        case 3 -> { /* ler id e g.marcarLido(id) */ }
        case 4 -> g.listarTodas().forEach(t -> System.out.println(t.lerId()+" - "+t.getTitulo()));
        case 5 -> g.listarFinalizadas().forEach(t -> System.out.println(t.getTitulo()));
        case 6 -> { /* ler id, titulo, descricao e g.alterar(...) */ }
    }
} while (op != 0);

🔐 Fluxo JWT

  1. Usuário envia e-mail/senha.
  2. Backend valida.
  3. Backend gera o token.
  4. Frontend guarda o token.
  5. Token vai nas requisições protegidas (header Authorization).
  6. Backend valida o token antes de liberar.

🗄️ Relacionamento 1:N

CONTA (1)———<(N) ANOTACAO

Uma conta tem muitas anotações; cada anotação pertence a uma conta (FK). Restrição: evitar duas anotações da mesma conta na mesma data (chave única).

Segurança: trocar MD5 por BCrypt/Argon2; segredo do JWT em variável de ambiente (não no código).
